Taskflow is a modern, fully functional To-Do List web application built using pure HTML, CSS, and JavaScript, no frameworks or backend required. It offers a premium productivity experience inspired by apps like Notion and Todoist, with a classic sage-green aesthetic and elegant serif typography.
Users can add, edit, delete, and complete tasks with smooth animations and instant feedback. Each task supports a title, category/tag, priority level (High / Medium / Low), and due date with overdue detection. The app includes live search, four filter tabs (All / Pending / Completed / High Priority), and three sort options (by created time, due date, or priority). Tasks can be reordered using drag and drop powered by SortableJS.
The dashboard displays four live stat cards and a progress bar tracking overall completion. A dark/light mode toggle, toast notifications, delete confirmation modal, and keyboard shortcuts (Enter to add, Esc to cancel) round out the user experience. All data is persisted in localStorage so tasks survive page refreshes.
